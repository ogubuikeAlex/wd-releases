## **Study Strategy for Fundamentals**

- December - Algorithm and DS + System Design Review
- January - Algo + System Design Reveiew + 3 Interviews converted to articles
- February - System Design Interviews, Inro to design patterns, Algo
- March - System Design Interviews, Depth on design patterns and Algo

### Step 1: Focus on Algorithms First
- Dedicate the reminaing part of december 2024 (**3 weeks**) to AlgoExpert to build a strong foundation.
- Complete Easy and Medium problems before moving to Hard ones.
- Practice writing clean, efficient code and explaining your solutions.

### Step 2: Gradually Introduce System Design
- After completing **60-70% of AlgoExpert**, begin learning SystemExpert.
- Study all foundational topics like caching, load balancing, and database choices.
- Spend 1-2 days per week on system design while continuing algorithm practice.

### Step 3: Merge Both Areas
- Dedicate **3-4 days** to AlgoExpert and **1-2 days** to SystemExpert weekly.
- Solve Hard problems on AlgoExpert and integrate system design concepts into projects.

## **Introducing Design Patterns**

### When to Start Learning
- Begin once you’ve mastered basic algorithms and system design concepts.
- Patterns naturally fit when you're working on scalable and reusable code.

### Why Patterns Matter
- Improve code readability and maintainability.
- Solve recurring problems with proven solutions.
- Help bridge the gap between low-level coding and high-level architecture.

---

## **How to Practice Design Patterns**

### Study Common Patterns
Focus on:
- **Creational:** Singleton, Factory, Builder.
- **Structural:** Adapter, Decorator, Proxy.
- **Behavioral:** Observer, Strategy, Command.

---

### Apply Patterns to Problems
- **Redo Existing Problems:** Refactor solutions with patterns (e.g., use Strategy for sorting or Factory for object creation).
- **Embed Patterns in Projects:** Use Singleton for caching in a URL shortener or Observer for chat notifications.

---

### Create Mini-Projects for Patterns
Examples:
- **Singleton:** Logger service that maintains a single instance.
- **Factory:** Dynamic shape creation tool.
- **Decorator:** UI customization tool for websites.
- **Observer:** Real-time stock price notification system.

### Tips for Practicing Patterns
1. Identify repetitive problems to find pattern use cases.
2. Write pure code without frameworks for deeper understanding.
3. Document why you chose a specific pattern and its trade-offs.
